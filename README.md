# CampusIQ
Our project is CampusIQ, an AI-powered college information assistant, Allows students to ask questions about faculty, departments, placements, special labs, achievements and reg college information through a chat interface. CampusIQ brings important college information into one place, allows students to access it through natural-language questions.
We used HTML, CSS and JavaScript for the frontend, Python and Flask for the backend, JSON for storing structured college data, web scraping for collecting faculty information, REST APIs for communication between frontend and backend, and basic natural-language processing techniques for understanding user questions.
WorkFlow:

   ↓
