🎓 CampusIQ
CampusIQ is a smart, campus-focused information assistant designed exclusively for students and members of Bannari Amman Institute of Technology (BIT). It provides a simple, ChatGPT-like interface where authorized users can ask questions related to campus facilities, academics, events, departments, rules, and other college-specific information.
The platform aims to reduce the time students spend searching through multiple sources by bringing relevant campus information into a single, accessible interface.
________________________________________
📌 Problem Statement
Students often need to search through college websites, notices, circulars, department pages, and other sources to find simple campus-related information.
This creates several challenges:
•	Difficulty finding the right information quickly.
•	Information scattered across multiple sources.
•	Repeatedly asking faculty or administrative staff for common information.
•	Difficulty accessing relevant information in a conversational manner.
•	Lack of a centralized campus-focused information assistant.
CampusIQ addresses this problem by providing a centralized, intelligent interface for accessing Bannari Amman Institute of Technology campus information.
________________________________________


💡 Project Overview

CampusIQ provides an interactive conversational interface that allows authorized users to ask campus-related questions naturally.
The system is designed around three main principles:
🔐 Secure Access Only users with an official "@bitsathy.ac.in" email address can access the platform.
🤖 Intelligent Assistance Users can ask questions in natural language instead of manually searching through different college resources.
📚 Campus-Focused Knowledge CampusIQ is specifically designed for BIT-related queries rather than functioning as a general-purpose chatbot.

✨ Key Features
🔐 Official College Email Login
•	Authentication using the official "@bitsathy.ac.in" email domain.
•	Prevents unauthorized users from accessing the campus assistant.
👋 Personalized Welcome
•	Displays a personalized welcome message after login.
•	Creates a user-friendly experience for students.
💬 ChatGPT-Like Interface
•	Clean and modern conversational interface.
•	Users can type questions and receive responses through the chat interface.
•	Designed for simple and intuitive interaction.
🗂️ Chat History
•	Maintains recent conversations.
•	Displays chat history through the sidebar.
•	Supports viewing conversations from the last 15 days.
➕ New Chat
•	Allows users to start a fresh conversation.
•	Keeps different conversations organized.
🚪 Logout
•	Provides a dedicated logout option.
•	Helps users securely end their session.
